What is an Invisible Character and How Does It Work?

An invisible character (often called a blank space, empty text, or hidden character) is a specialized Unicode code point that renders without displaying any visible ink or glyph on the screen. While to the human eye the screen appears empty, modern operating systems and web applications recognize the code point as an authentic typographic character.

Most online platforms, messaging applications (like WhatsApp and Telegram), and gaming databases automatically execute an input sanitation filter (such as trim()) when you submit a form. This filter strips away standard spacebar spaces (ASCII code 32 / U+0020). However, specialized Unicode characters—such as the Hangul Filler (U+3164) or the Zero-Width Space (U+200B)—bypass these automatic filters, allowing you to submit empty messages, hide user nicknames, or format custom paragraph breaks.

Standard spacebar presses produce the ASCII space character (U+0020). When you tap send or save, chat apps run an automatic check to see if the message contains only whitespace. U+3164 has a visible typographical width equal to one full Korean character (it occupies physical space on the screen, like a regular letter, but has no pixels). U+200B, on the other hand, is a zero-width character (it takes up zero pixels of horizontal space). That is why U+3164 is superior for usernames and names, whereas U+200B is superior for WhatsApp empty messages.

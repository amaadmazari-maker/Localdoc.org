Technical Architecture: ISO 32000-1 Security Handlers & In-Memory Cryptographic Hardening

Under the ISO 32000-1 Section 7.6 and ISO 32000-2 Section 7.6 standards, PDF documents control access rights through standardized encryption dictionaries (/Encrypt), cryptographic password hashes, and a signed 32-bit permissions bitmask (/P). While commercial cloud converters upload plaintext contracts to remote servers to apply security filters—exposing proprietary data to breach vectors—LocalDoc executes all cryptographic key derivation and stream protection inside client browser RAM:

  • ISO 32000-1 Permissions Bitmask Math (/P Flag): Access rights are governed by a signed 32-bit integer. Compliant PDF readers (Adobe Acrobat, Apple Preview, Google Chrome) evaluate specific bit flags:
    • Bit 3 (Print Permission): Governs normal quality printing rights.
    • Bit 4 (Modify Contents): Controls document editing, form page insertion, and rotation.
    • Bit 5 (Extract Text & Graphics): Controls clipboard copying and text extraction.
    • Bit 6 (Annotations & Form Fields): Authorizes digital signatures and interactive comment markup.
    • Bit 9 (Fill In Existing Forms): Authorizes interactive form filling even when general editing is disabled.
    • Bit 12 (High-Fidelity Printing): Governs digital press and high-resolution print reproduction.
  • AES-256 (Revision 6) Encryption Architecture: LocalDoc generates 256-bit AES encryption keys using browser-native crypto.subtle primitives. The document catalog, content cross-reference tables, and all stream objects are re-encrypted object-by-object.
  • Decryption & Password Removal: When an encrypted file is uploaded with valid credentials, LocalDoc parses the encryption dictionary, validates the user or owner password hash, batch-decrypts all binary streams, removes the /Encrypt trailer reference, and produces a completely unlocked PDF.
  • Metadata Sanitization & Privacy Scrubbing: Prior to compiling the final binary, LocalDoc provides automatic stripping of lingering document metadata (/Author, /Creator, /Producer, creation timestamps, and hidden XML packets in /Metadata), preventing inadvertent leakage of author names, internal corporate server paths, or printer serial numbers.
  • Zero-Egress In-Memory Quarantine: All cryptographic operations, typed Uint8Array buffers, and intermediate encryption states exist exclusively within ephemeral JavaScript closures. Once the encrypted document Blob URL is generated, all memory structures are marked for immediate V8 engine garbage collection with zero disk or telemetry footprint.

Frequently Asked Questions About PDF Protection & Security

Can someone copy text out of my PDF if I disable 'Allow Copying'?

Compliant PDF viewing software (including Adobe Acrobat, Apple Preview, and modern browser PDF viewers) strictly honor the PDF permissions bitmask, disabling the "Copy" command, text selection, and print buttons. For maximum security, pair permissions with an Open Password.

What is the difference between an Open Password and a Permissions Password?

An Open Password (User Password) prevents anyone from viewing the document content without entering the key. A Permissions Password (Owner Password) permits viewing without a prompt but blocks editing, printing, or extracting text without entering the owner password.

Does LocalDoc retain any backup copy or master key to unlock my file?

No. LocalDoc has no backends, accounts, or databases. There is no master key. If you set a document password, make sure to store it in a reliable password vault.

Can I decrypt and unlock a password-protected PDF with LocalDoc?

Yes. If you know the password to a locked document, upload it to LocalDoc, switch to the Unlock & Decrypt PDF tab (or let our auto-detector switch automatically), enter your password, and click Unlock. All encryption and restriction flags will be permanently removed.

Can I protect a PDF from an iPhone or Android smartphone?

Yes. LocalDoc is fully optimized for mobile browsers and PWA installation. You can lock or unlock files directly on your mobile device without installing heavy native software.

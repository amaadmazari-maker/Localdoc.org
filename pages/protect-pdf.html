Technical Architecture: ISO 32000-1 Standard Security Handlers

Document security in the Portable Document Format is defined under ISO 32000-1 Section 7.6 (Security). PDF security handlers manage access through document encryption dictionaries (/Encrypt) and permissions flags (/P):

  • Permissions Bitmask Encoding (/P Flag): A 32-bit integer dictates document permissions. Bit 3 controls printing rights, bit 5 controls content copying and text extraction, and bit 4 controls document modifications. LocalDoc computes the exact bitmask (e.g. -3904) and injects it into the trailer dictionary.
  • Tamper-Evident Header Vector Overlays: Security seals (e.g. "PROTECTED & CONFIDENTIAL") are rendered directly into each page's content stream using vector font commands with high-visibility color metrics, preventing effortless cropping without invalidating page content streams.
  • Zero-Upload Memory Quarantine: Traditional online PDF tools upload your unencrypted contracts to remote cloud servers to process security stamps, introducing catastrophic corporate espionage vectors. LocalDoc executes exclusively in volatile RAM.

Frequently Asked Questions About PDF Protection

Can someone copy text out of my PDF if I enable 'Restrict Content Copying'?

Compliant PDF viewing software (including Adobe Acrobat, Apple Preview, and modern browser PDF viewers) strictly honor the PDF permissions bitmask, disabling the "Copy" command, text selection, and print buttons. However, anyone can still view the on-screen text or take a manual screenshot.

Does LocalDoc retain any backup copy or master key to unlock my file?

No. LocalDoc has no backends, accounts, or databases. There is no master key. If you set a document password, make sure to store it in a reliable password vault.

Can I protect a PDF from an iPhone or Android smartphone?

Yes. LocalDoc is fully optimized for mobile browsers and PWA installation. You can lock files directly on your mobile device without installing heavy native software.

What is the difference between an Open Password and Permissions Password?

An Open Password (User Password) prevents anyone from viewing the document content without entering the key. A Permissions Password (Owner Password) permits viewing but blocks editing, printing, or extracting text.

PDF Security Standard Notes

Non-Standard PDF Viewers: Certain third-party open-source PDF viewers (such as Linux pdftotext or uncertified mobile readers) intentionally bypass permission flags because PDF permissions are an honor-system standard rather than cryptographic DRM. For total secrecy, always enforce a strong User Password.

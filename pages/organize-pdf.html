Technical Architecture: In-Memory PDF Page Tree Restructuring

In accordance with ISO 32000-1, a PDF document represents its layout hierarchy as an acyclic directed graph rooted at the document catalog (/Catalog). The pages are linked through an internal balanced B-tree dictionary (/Pages) containing an ordered array of object references (/Kids [12 0 R 15 0 R ...]).

  • Lossless /Rotate Metadata Injection: When you rotate a page 90 degrees in LocalDoc, the underlying raster images and font vectors are not recompressed or rasterized. Instead, the page dictionary's /Rotate integer tag is updated (0, 90, 180, 270 degrees). This guarantees 100% lossless visual preservation.
  • /Kids Array Index Splicing: Reordering pages involves rearranging the indirect object reference pointers inside the parent /Pages dictionary. Deleting a page removes its pointer from /Kids and decrements the cumulative /Count integer.
  • Cross-Document Page Transplantation: When you append supplementary PDF files, LocalDoc imports foreign page nodes, remaps indirect object IDs to prevent collisions, and links them seamlessly into the active page tree.
  • Volatile Memory Isolation: All calculations execute in sandboxed WebAssembly and JavaScript threads. No documents or thumbnails are posted to external web servers, protecting sensitive financial audits and legal records.

Frequently Asked Questions About Organizing PDFs

Can I undo accidental page deletions?

Yes. Changes remain in your browser's temporary working memory until you click 'Save & Download PDF'. If you accidentally remove an important page, simply re-add the original file to restore it.

Does rotating a page make text blurry or degrade image quality?

No. Rotating changes only the viewport orientation tag in the PDF catalog. The underlying vector paths, TrueType fonts, and high-resolution scanned bitmaps are preserved untouched at 100% original quality.

Can I organize a PDF that contains mixed page sizes (A4, Letter, Legal)?

Yes. Each page preserves its individual /MediaBox and /CropBox dimensions. You can freely interleave landscape CAD drawings with standard portrait letter pages without distortion.

Is there a limit to how many pages I can organize at once?

There are no artificial software limits. Documents with 100+ pages are handled smoothly on modern laptops and desktop computers. For older mobile phones, organizing in batches of 30 to 50 pages is recommended.

Interactive Touch & Mobile Reordering Guidance

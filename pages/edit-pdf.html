Technical Architecture: In-Memory /CropBox Geometry & Vector Stream Composition

In accordance with ISO 32000-1, a PDF document represents its layout hierarchy as an acyclic directed graph rooted at the document catalog (/Catalog). LocalDoc performs non-destructive page surgery in browser RAM without quality loss:

  • Lossless /CropBox vs /MediaBox Adjustment: When cropping pages, generic tools rasterize vector layouts into blurry JPEG images. LocalDoc leaves the underlying vector stream and TrueType font glyphs 100% untouched, instead rewriting the page dictionary's /CropBox [xLL yLL xUR yUR] array. PDF viewers display only the cropped region while preserving crystal-clear vector text.
  • Fluorescent Multi-Layer Blending: Highlighter annotations utilize hardware-accelerated multiply composite blend mode at 45% alpha opacity. This guarantees that underlying black text, table gridlines, and signatures remain 100% visible and sharp underneath yellow, green, pink, or cyan highlights.
  • Directional Vector Arrows & Shapes: Straight lines, single arrows, and double-headed arrows are calculated with polar trigonometry (atan2) and projected with sub-millimeter precision into the document overlay stream.
  • Zero-Cloud Memory Isolation: All calculations execute in sandboxed WebAssembly and JavaScript threads. No documents or thumbnails are posted to external web servers, protecting sensitive financial audits and legal records.

📟 Casio fx-5800P Programming & Function Handbook

The Casio fx-5800P SUPER-FX PLUS allows students, surveyors, and civil/electrical engineers to store and run up to 4 persistent custom programs directly on the 4-line dot-matrix LCD display.

▶ How to Run a Program

  1. Press FILE (Prog) to open the on-screen program menu.
  2. Press 1, 2, 3, or 4 to select your program slot (e.g. 4 for Survey Inverse).
  3. When prompted on the LCD (e.g. A?), type your coordinate value and press EXE.
  4. When ◢ blinks, press EXE to view the next output.

✍️ Program Syntax Commands

  • ?→A: Prompts user on LCD for variable A.
  • expr→D: Stores formula result into variable D.
  • :: Statement separator for sequential execution.
  • cond=>act: Conditional branch (e.g. T<0=>T+360→T).
  • ◢: Output pause symbol (shows result on LCD until EXE).

🗺️ Land Surveying: Pol(ΔN, ΔE) Bearing & Distance

Surveyors can enter Pol(N1-N2, E1-E2) directly on the keypad to calculate horizontal distance and whole-circle bearing between any two control points:

  • Line 3 displays: Distance r (stored into memory register X).
  • Line 4 displays: Bearing θ in decimal and DMS DD°MM'SS" (stored into Y).
  • Press ° ' " (DMS) to toggle angles between decimal degrees and sexagesimal notation.
  • Run built-in P4: SURVEY-INV from the FILE menu to calculate traverse inverse legs interactively.

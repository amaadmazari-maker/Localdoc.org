Technical Architecture: Programmable BASIC AST Interpreter & Numeric Precision

Unlike simplistic web calculators that blindly pass unsanitized input strings into JavaScript's imprecise eval() function, LocalDoc operates a dedicated tokenizer, Pratt recursive-descent expression parser, and Abstract Syntax Tree (AST) interpreter entirely within browser memory:

Tokenizer & Operator Precedence Parsing

Mathematical expressions are broken into typed token streams (numeric literals, exponential scientific notation 1.23e-8, constants π and e, algebraic operators, and memory registers A–Z). Our Pratt recursive-descent parser enforces textbook algebraic hierarchy: unary negation vs binary subtraction, implied multiplication (e.g. 2(3+4) or 5π parsed without requiring explicit * symbols), and right-associative exponentiation (2^3^2 = 512).

IEEE 754 Floating-Point & Epsilon Guarding

Native JavaScript numbers are IEEE 754 64-bit double-precision floats, which regularly suffer binary fractional rounding inaccuracies (e.g. 0.1 + 0.2 === 0.30000000000000004 or sin(π) === 1.2246e-16). LocalDoc wraps all trigonometric and algebraic reductions in an epsilon-guarded quantization formatter (Number.EPSILON) that cleans floating-point noise to 12 decimal places before updating the LCD display.

Composite Simpson Calculus & Survey Coordinates

Definite integrals (∫dx) are approximated via adaptive composite Simpson's 1/3 and 3/8 quadrature rules with singularity guards (triggering Math ERROR at asymptotes like tan 90°). Surveying coordinates (Pol / Rec) compute Euclidean hypotenuse and whole-circle azimuth bearings (ΔN, ΔE) using quadrant-aware Math.atan2() transformations.

Sandboxed BASIC Runner & Offline PWA Memory

Program slots (P1–P4) parse variable input prompts (?→A), conditional branches (cond=>statement), and pause delimiters (◢). Each execution runs with a 50ms timeout guard to prevent runaway infinite loops, while all 26 variable registers (A–Z) and calculation tape logs are serialized locally in browser localStorage.

Common Practical Questions & Technical Troubleshooting

Technical guidance for programming, engineering coursework, and formula evaluation:

How do I toggle angle measurements between Degrees, Radians, and Gradians?

Press SHIFT then MODE to access the setup menu. Press 1 for Deg (°), 2 for Rad (radians), or 3 for Gra (gradians). The active mode flag (D, R, or G) will illuminate on the top status row of the LCD display.

How do I run and edit the built-in surveying inverse program?

Press the FILE (Prog) key on the upper keypad. Press 4 to launch SURVEY-INV. The screen prompts for N1?, E1?, N2?, and E2?. Enter each coordinate followed by EXE. The calculator outputs the precise horizontal distance, followed by the whole-circle azimuth bearing in degrees, minutes, and seconds (DMS).

Does this calculator support hexadecimal and binary calculations?

Yes. Press MODE, then select Base-N. Use the direct keys DEC (x²), HEX (log), BIN (ln), and OCT (xy) to instantly toggle display bases. Numbers entered are parsed in the active radix, allowing smooth bitwise operations.

Are my saved programs and calculation reel saved when I close the browser?

Yes. All four program slots (P1 through P4), the 26 memory registers (A–Z), and the calculation tape history are automatically serialized into your browser's persistent localStorage. They will remain available whenever you return to the site.

Can I use physical keyboard keys to enter expressions quickly?

Yes. The calculator supports full desktop keyboard input: numbers 0-9, decimal point ., operators +, -, *, /, parenthesis ( and ), Enter for EXE, and Backspace for DEL.

Is this emulator compliant for university examinations and engineering tests?

The mathematical algorithms follow official Casio fx-5800P firmware logic for numerical calculus and algebraic hierarchy. While physical hardware is typically required inside physical test halls, this online tool is ideal for homework verification, field survey preparation, and engineering practice.

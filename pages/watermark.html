Frequently Asked Questions

Can I remove a watermark I added using this tool?

Once applied and downloaded, the watermark is baked into the PDF as a permanent page element. To modify it, you would need to re-watermark the original PDF. Always keep a copy of the unwatermarked original.

What opacity level looks best for a diagonal watermark?

For diagonal watermarks like "CONFIDENTIAL", an opacity of 15–25% is typically ideal. It remains clearly visible on screen and in print while keeping the main content readable underneath.

Is the watermarked PDF compatible with Adobe Acrobat?

Yes. The output is a standard ISO 32000-compliant PDF file, compatible with Adobe Acrobat Reader, Preview on Mac, and all major PDF viewers on any platform.

Can I add an image watermark instead of text?

The current version supports text watermarks with full customization of font, size, colour, opacity and rotation. Image watermark support is planned for a future update.

Frequently Asked Technical Questions

What types of watermarks can I add to a PDF?
LocalDoc supports: (1) diagonal text watermarks with configurable opacity (10–100%), font size, and colour. (2) Image watermarks (PNG/SVG with transparency). (3) Repeating tile watermarks across all pages using PDF stream operators.
Are watermarks in LocalDoc truly permanent?
LocalDoc adds watermarks as flat content stream operators at the page level — they are not annotation layers. A determined user with Acrobat Pro can still remove them. For tamper-proof watermarking, consider PDF/A archival with embedded metadata.
Can I watermark just specific pages?
Yes. The page range selector allows watermarking page 1 only, odd/even pages, or a custom range (e.g. pages 3–18). Great for marking draft sections of a document.
What font families are available for text watermarks?
Helvetica, Times-Roman, Courier (all PDF built-in standard fonts), plus any custom font you upload as a .ttf or .woff2 file — decoded in-browser via opentype.js.

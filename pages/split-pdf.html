Technical Architecture: Selective Object Subgraph Extraction

In accordance with ISO 32000-1, PDF documents represent pages as nodes in a balanced B-tree. Simply slicing out binary bytes results in broken cross-reference tables and corrupt files. LocalDoc performs precise object graph surgery inside your browser:

  • Page Node Isolation & Root Re-indexing: When you specify target pages (e.g. 12 through 15), LocalDoc traverses the document's page tree, locates the corresponding leaf nodes, and constructs a new independent /Catalog and /Pages dictionary referencing only the selected nodes.
  • Deep Resource Graph Cloning: Embedded TrueType fonts, form XObjects, vector drawing graphics states, and bitmap DCTDecode streams referenced by the chosen pages are cloned into the output document's indirect object space. Redundant assets from unselected pages are completely excluded, ensuring compact file sizes.
  • Client-Side JSZip Burst Streaming: When 'Burst' mode is active, each page is encapsulated into its own self-contained PDF container with its own valid XRef table, then streamed into a compressed ZIP file using in-memory DEFLATE compression.
  • Total Privacy Isolation: No documents are transmitted across the internet. Execution occurs in sandboxed WebAssembly and JavaScript threads, ensuring complete compliance with HIPAA, GDPR, and confidential corporate NDAs.

Frequently Asked Questions About Splitting PDFs

Can I extract non-consecutive pages like pages 2, 5, and 11 into one PDF?

Yes. You can simply click on thumbnails #2, #5, and #11, or enter "2, 5, 11" into the page range field. LocalDoc will combine only those three pages into a single cohesive PDF.

What page range syntax formats are supported?

LocalDoc supports standard printing syntax: commas separate distinct pages or ranges (e.g. 1, 4, 7), hyphens define continuous intervals (e.g. 3-8), and combined entries (e.g. 1-3, 5, 8-12) are parsed automatically.

Will splitting a PDF reduce the visual quality or text sharpness?

No. Splitting is a 100% lossless structural operation. The original vector fonts, high-resolution raster images, and mathematical layout coordinates are cloned byte-for-byte into the new document container.

What is the maximum number of pages LocalDoc can split?

Because processing runs locally using your device's memory, documents with 200 to 500+ pages can be split without issue on modern desktop and mobile browsers. There are no server-side queue limits.

Can I delete specific pages from a document rather than splitting?

Yes. You can either select all pages except the unwanted ones and click 'Extract', or use our companion Organize PDF tool to delete and reorder pages interactively.

Syntax Validation & Large Document Handling

Page Number Validation: Page numbers must be within the actual page count of the document. If your file has 20 pages and you enter "15-25", LocalDoc will automatically clamp the upper bound to page 20.

Bursting 100+ Page Documents on Mobile: Generating over 100 separate PDF files and compressing them into a ZIP archive creates substantial memory allocation. If using an older smartphone, extract chapters in batches of 20 to 30 pages to prevent tab memory refreshes.

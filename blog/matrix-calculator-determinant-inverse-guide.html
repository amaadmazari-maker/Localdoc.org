  • 2×2 Inverse: A−1 = (1 ⁄ (ad − bc)) × [ d   −b ;   −c   a ] (swap main diagonal, negate anti-diagonal).

1. The 2×2 Matrix: Determinants and Inverses

A second-order square matrix contains four scalar entries arranged in two rows and two columns:

A = [ a   b ;   c   d ]

Determinant Calculation

The determinant represents the signed area scaling factor of the linear transformation defined by the matrix:

det(A) = |A| = (a × d) − (b × c)

Worked Example: Let A = [ 4   7 ;   2   6 ]
det(A) = (4 × 6) − (7 × 2) = 24 − 14 = 10

Inverse Matrix Calculation

The inverse A−1 is the unique matrix satisfying A × A−1 = I, where I = [ 1   0 ;   0   1 ] is the identity matrix.

Steps for 2×2 Inverse:
  1. Calculate ( det(A) = ad - bc ). If zero, stop — matrix is singular!
  2. Swap main diagonal elements: ( a ) and ( d ) trade places.
  3. Negate the other two elements: ( b ) becomes ( -b ), and ( c ) becomes ( -c ).
  4. Multiply the resulting adjugate matrix by 1⁄det(A).
For A = [ 4   7 ;   2   6 ]:
A−1 = 1⁄10 × [ 6   −7 ;   −2   4 ] = [ 0.6   −0.7 ;   −0.2   0.4 ]

2. The 3×3 Matrix: Determinant via Sarrus Rule

For a third-order matrix:

A = [ a   b   c ;   d   e   f ;   g   h   i ]

The Sarrus Rule Walkthrough

The Sarrus rule is an intuitive geometric shortcut applicable specifically to 3×3 matrices:

  • Primary Diagonals (+): Multiply entries down-right:
    D1 = (a × e × i) + (b × f × g) + (c × d × h)
  • Secondary Diagonals (−): Multiply entries up-right / down-left:
    D2 = (c × e × g) + (a × f × h) + (b × d × i)
  • Combine:
    det(A) = D1 − D2

Worked Numerical Example:

Let A = [ 1   2   3 ;   0   1   4 ;   5   6   0 ]

Primary: (1×1×0) + (2×4×5) + (3×0×6) = 0 + 40 + 0 = 40
Secondary: (3×1×5) + (1×4×6) + (2×0×0) = 15 + 24 + 0 = 39
det(A) = 40 − 39 = 1

3. Solving Linear Systems with Cramer's Rule

Cramer's Rule uses determinants to solve a system of linear equations directly without performing row reduction (Gaussian elimination). Consider the 2-variable system:

a1x + b1y = c1
a2x + b2y = c2

Coefficient Determinant: D = | a1   b1 ;   a2   b2 | = a1b2 − b1a2
X-Determinant: Dx = | c1   b1 ;   c2   b2 | = c1b2 − b1c2
Y-Determinant: Dy = | a1   c1 ;   a2   c2 | = a1c2 − c1a2

Solutions: x = Dx ⁄ D and y = Dy ⁄ D (Provided D ≠ 0)

How to Batch Scan Invoices, Multi-Page Receipts & Organize to PDF

AM Amaad Mazari Lead Security Architect Updated September 2026 8 Min Read

Key Takeaways & Executive Summary

Digitizing high-volume paper documents—such as multi-page invoices, legal settlement packets, and thermal expense receipts—traditionally forced users to choose between cumbersome flatbed scanners or intrusive cloud scanning mobile apps that upload unencrypted scans to remote databases. LocalDoc provides an in-browser batch scanning engine combining real-time camera viewfinder frame capture, continuous corner detection, Sauvola local adaptive binarization, and client-side multi-page PDF compilation in local hardware RAM with zero cloud telemetry.

1. The Challenge of High-Volume Document Digitization

Corporate accounting departments, legal paralegals, and mobile field engineers frequently process stacks of physical documents under challenging conditions: uneven indoor lighting, crumpled thermal receipts with faded inks, and perspective distortion from handheld phone cameras.

Legacy smartphone scanner applications (e.g., CamScanner, Adobe Scan) address this by uploading full-resolution camera captures to proprietary cloud servers for computer-vision processing. This architecture introduces severe compliance liabilities: financial records, customer tax identifiers, and proprietary invoices are exposed to cloud database breaches and third-party data profiling. LocalDoc solves this by executing the entire computer-vision pipeline in browser memory using WebAssembly and WebGL shaders.

Figure 1: Client-Side Batch Scanning Pipeline — In-Memory Computer Vision and PDF Assembly

2. In-Memory Queue Architecture & Zero-Copy Canvas Buffers

When capturing a multi-page stack, capturing speed is critical. If each frame required blocking computation, the camera viewfinder would stutter. LocalDoc decouples image acquisition from raster processing through an asynchronous ring buffer:

  • Non-Blocking Capture Thread: The live camera feed streams via navigator.mediaDevices.getUserMedia(). Clicking the burst trigger snatches an uncompressed video frame onto an offscreen HTMLCanvasElement.
  • Zero-Copy Worker Transfer: Raw pixel buffers are packaged as ImageBitmap structures and transferred directly to background Web Workers using transferable object pointers. This eliminates memory-cloning overhead and prevents UI thread dropped frames.
  • Dynamic Page Reordering: Captured pages appear instantly in a responsive thumbnail queue. Users can rotate individual pages, reorder sequence indices via drag-and-drop, or remove accidental captures before final PDF assembly.

3. Image Enhancement: Sauvola Binarization & Perspective Rectification

Raw smartphone photographs suffer from shadows, wrinkled paper, and perspective skew. To produce crisp, printer-ready documents, LocalDoc applies a three-stage mathematical filter chain in WebAssembly:

  1. Corner Detection & Homography Warping: Canny edge gradients identify document boundaries. A 3x3 homography matrix projects the quadrilateral onto a standardized flat A4 plane (2,480 x 3,508 pixels at 300 DPI).
  2. Integral Image Calculation: A sum-table integral image enables local window variance computations in constant O(1) algorithmic time.
  3. Sauvola Adaptive Thresholding: Unlike global thresholding algorithms (such as Otsu's method) that turn shadowed corners pitch black, Sauvola evaluates local pixel variance: T = m * (1 + k * (s / R - 1)). This separates faded thermal receipt text from gray backgrounds with surgical precision.

6. Honest Technical Limitations of Smartphone Browser Scanners

Operating computer-vision pipelines inside a web browser requires realistic understanding of hardware boundaries:

  • Thermal Throttling Under Extended Bursts: Continuously streaming high-resolution 4K video feeds while executing real-time Sauvola matrix filters can generate substantial thermal load. On mid-range mobile devices, processing bursts exceeding 35 to 40 consecutive pages may cause browser throttling.
  • Non-Planar Curved Bindings: The perspective rectification algorithm assumes planar flat documents. Tightly bound hardcovers or thick books with deep spine gutters exhibit non-planar page curvature that planar homography cannot fully straighten.
  • Low-Ambient Sensor Noise: Under extreme low-light conditions (<50 lux), smartphone camera sensors introduce heavy chroma noise that degrades edge detection accuracy, requiring manual corner adjustment in the cropping UI.

7. Frequently Asked Questions

Does LocalDoc save my scanned receipts or invoices on a server?

Never. All camera streams and captured image frames are processed strictly inside volatile browser memory. No backend storage servers or intermediate cloud queues exist.

Can I scan documents when my phone is in Airplane Mode?

Yes. Once LocalDoc is loaded in your browser or installed via our Progressive Web App (PWA), all scanning and PDF generation algorithms run completely offline without an active network connection.

How does Sauvola thresholding improve thermal receipts?

Thermal receipts often suffer from faded print and uneven wrinkles. Sauvola thresholding dynamically calculates local contrast variations across a moving window, ensuring low-contrast text is sharpened into crisp black text on a clean white background.

What is the maximum number of pages I can batch scan in one session?

Most desktop browsers can easily process batches of 100+ pages. On mobile devices with memory constraints, we recommend scanning batches of 25 to 35 pages per PDF package to prevent mobile browser tab memory limits.

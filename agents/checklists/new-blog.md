# Checklist: New Blog / Guide Release (`new-blog.md`)

Required checklist for Lead 3 and Lead 1 before submitting any new blog post or tutorial guide to the Manager Agent.

- **Title:**
- **URL Path:**
- **Author:**
- **Target Keyword:**

---

## 1. Editorial & Substance (Lead 3 Writer & Editor)
- [ ] Based on real, first-hand testing of the tool or workflow.
- [ ] Step-by-step instructions tested and verified by writer.
- [ ] Free of AI fluff, repetitive filler, and empty introductory padding.
- [ ] Concise sentences with clear headings (H2, H3 hierarchy).
- [ ] Real FAQs addressing genuine user pain points.
- [ ] Readability and spelling checked by Language / Editor Agent.

## 2. Visuals & Media (Lead 3 Screenshot Agent)
- [ ] High-resolution, real screenshots captured directly from localdoc tools.
- [ ] Converted to modern WebP format with high visual fidelity and low file weight.
- [ ] Every image includes descriptive, context-specific `alt` text.
- [ ] Zero synthetic, stock, or generic mockups used.

## 3. SEO & Technical Structure (Lead 1 SEO Agent)
- [ ] Unique `<title>` tag (50-60 characters) containing primary keyword.
- [ ] Meta description (150-160 characters) with clear value proposition.
- [ ] Canonical tag is self-referential and absolute.
- [ ] Open Graph (`og:title`, `og:description`, `og:image`) and Twitter Card configured.
- [ ] Schema.org JSON-LD (`Article`, `HowTo`, `BreadcrumbList`) validated without errors.
- [ ] Minimum 3 contextual internal links pointing to relevant localdoc tools or related guides.
- [ ] URL added to `sitemap.xml`.

## 4. Trust & Authority (Lead 3 Author Agent)
- [ ] Real author byline linked to author profile.
- [ ] Published date and last updated date visible.
- [ ] Review checkbox completed by Human Owner (Section 12).

## 5. Device & QA Verification (QA Team)
- [ ] Verified across mobile (Android/iOS) and desktop breakpoints.
- [ ] Images scale responsively without horizontal blowout.
- [ ] Zero broken links or console errors.
- [ ] QA sign-off attached.

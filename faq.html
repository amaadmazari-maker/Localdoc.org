Knowledge Base

Frequently Asked Questions

Clear answers regarding our client-side architecture, processing speeds, and privacy safeguards.

1. How is LocalDoc completely zero-upload?

LocalDoc compiles its file transformation libraries (pdf-lib, pdf.js, SheetJS, and Tesseract.js) to pure client-side JavaScript and WebAssembly. When you drop a document into any tool, the file binary stays entirely inside your browser's private memory sandbox. No network requests are made.

2. Are there any daily document conversion limits?

No! Because transformations run on your own hardware rather than expensive cloud servers, you can process unlimited files without paying anything or waiting in queues.

3. Can I use LocalDoc without an internet connection?

Yes. After your first visit, our Progressive Web App (PWA) cache allows you to open LocalDoc and use all 20 tools completely offline without any internet connection.

4. What are the exact dimensions for NADRA CNIC photos?

Pakistani NADRA CNIC smart card photos must be exactly 354x472 pixels at 300 DPI with a blue or light background. Our CNIC Photo Maker handles this aspect ratio and 4x6" print grid generation automatically.

5. How does the ID Card Front & Back 1-Page A4 Mode work in LocalDoc Scanner?

In LocalDoc's Document Scanner, you can snap or upload both the Front and Back of any government ID card, driving license, or passport. The engine automatically lays them out on a single standard 300 DPI A4 page with 1:1 physical card slots and alignment guidelines ready for official portal submissions.

6. Is my data safe if I close the browser tab?

Yes. Because all data is held strictly in volatile RAM, closing the browser tab permanently frees the memory, leaving zero residual traces on our servers or your hard drive.

PDF Tools — Common Questions

7. How does LocalDoc compress PDF files without re-uploading them?

Our Compress PDF tool uses pdf-lib running entirely in WebAssembly inside your browser. It re-encodes embedded images at reduced quality levels and strips redundant metadata — all without your file leaving your device. Compression ratios of 60–85% are common for image-heavy PDFs.

8. Can I merge password-protected PDFs?

Our Merge PDF tool can combine unprotected PDFs. Password-protected files will need to be unlocked first. If you need to remove password protection, use the PDF Security tool to set permissions before merging.

9. What languages does the OCR (Image to Text) tool support?

The Image to Text tool uses Tesseract.js compiled to WebAssembly and supports over 40 languages, including English, Urdu, Arabic, French, Spanish, German, Hindi, Chinese, and many more. Language packs are loaded on-demand directly into your browser.

10. How accurate is LocalDoc's document scanner compared to dedicated scanner apps?

LocalDoc's Document Scanner uses adaptive luminance thresholding and histogram stretching algorithms to remove shadows, flatten paper curves and enhance ink contrast. For well-lit documents, output quality is comparable to dedicated scanning apps. For best results, scan on a flat, contrasting surface in good lighting.

Photo ID Tools — Common Questions

11. Which passport photo sizes are supported?

The Passport Photo Maker and ID Photo Studio support US (2×2 inch), UK (35×45mm), EU/Schengen (35×45mm), Pakistan CNIC (354×472px), and many other country-specific formats. All cropping and background adjustments are done locally in your browser.

12. Does background removal work automatically for ID photos?

Yes. The ID photo tools include automatic background detection and replacement. You can choose from standard white, light grey, blue or custom background colours. The AI-powered segmentation runs entirely in your browser with no server calls.

13. Can I install LocalDoc as an app on my phone?

Yes. LocalDoc is a full Progressive Web App (PWA). On Android, tap the browser menu and select "Add to Home Screen". On iPhone (iOS 16.4+), open Safari, tap Share, then "Add to Home Screen". The app will install with its own icon and works completely offline after the first load.

14. How does LocalDoc handle my data after I close the tool?

LocalDoc stores only your app preferences (dark mode, language, cookie consent) in your browser's localStorage. No document data, image data or file content is ever stored on disk or in any database. When you close the browser tab, all file data held in RAM is immediately and permanently erased. See our Privacy Policy for full technical details.
